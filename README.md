# 📁 Local Repo Project

A first Git exercise from the **ALX Software Engineering** programme: create a repository locally, make a commit, and push it to GitHub.

![Git](https://img.shields.io/badge/Git-F05032?style=flat-square&logo=git&logoColor=white)

## What I practised

- `git init` to turn a local folder into a repository
- `git add` and `git commit` to record a first file ([`hello.txt`](hello.txt))
- `git remote add origin` and `git push` to publish it on GitHub
